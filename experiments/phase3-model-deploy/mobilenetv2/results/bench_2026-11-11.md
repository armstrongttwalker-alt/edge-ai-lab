Key findings:
- QDQ quantization (onnxruntime built-in) works without NeuralONE SDK / cixbuild
- All 313 MobileNetV2 nodes run on NPU, zero CPU fallback
- 8.6x speedup over CPU for real vision model (vs 0.5x for tiny sigmoid model)
- This confirms NPU advantage on compute-intensive workloads (224x224 conv-heavy model)
- Model files: mobilenetv2_fp32.onnx (14MB) + mobilenetv2_qdq.onnx (3.5MB)
- Quantization: quantize_static with QDQ format, random calibration data, QInt8 weights+activations
