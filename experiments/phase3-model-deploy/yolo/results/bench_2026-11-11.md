Key findings:
- 17.8x speedup on 640x640 detection model vs 8.6x on 224x224 classification
- NPU advantage grows with larger input / more complex model
- QDQ quantization works without NeuralONE SDK (same approach as MobileNetV2)
- Output (1,84,8400) correct: 84 = 4 bbox coords + 80 COCO classes, 8400 = detection grid
- Model files: yolov8n_fp32.onnx (13MB) + yolov8n_qdq.onnx (3.5MB)

NPU acceleration summary across all models:
  sigmoid/mul_1 (tiny): NPU 0.57x CPU (NPU overhead dominates for small tensors)
  MobileNetV2 (224x224): NPU 8.6x CPU
  YOLOv8n (640x640):     NPU 17.8x CPU
  -> Trend: larger model = greater NPU advantage
