# Phase 4 FastAPI 推理网关 测试结果
# Date: 2026-11-11
# Device: Radxa Orion O6N (CIX P1)
# Service: uvicorn + FastAPI 0.162.4, port 8000

## 端点测试结果

| 端点 | 方法 | 状态 | 延迟 | 说明 |
|---|---|---|---|---|
| /health | GET | ✅ | <5ms | 服务健康检查 |
| /v1/models | GET | ✅ | <5ms | 列出 3 个模型 |
| /v1/vision/classify | POST | ✅ | 2.51ms | NPU MobileNetV2 分类 |
| /v1/vision/detect | POST | ✅ | 13.36ms | NPU YOLOv8n 检测，8400 框 |
| /v1/chat/completions | POST | ✅ | ~150ms | LLM 对话（11 token prompt）|

## 架构验证

```
客户端 (curl/Open WebUI)
  ↓
FastAPI Gateway :8000
  ├─ /v1/chat/completions → llama-server :8080 (Qwen2.5-1.5B Q8_0)
  ├─ /v1/vision/classify → ONNX NPU (MobileNetV2 QDQ, ZhouyiEP)
  └─ /v1/vision/detect   → ONNX NPU (YOLOv8n QDQ, ZhouyiEP)
```

## 关键验证点

- ✅ 统一入口：一个端口（8000）路由 LLM 和视觉模型
- ✅ OpenAI 兼容：/v1/chat/completions 返回标准 OpenAI 格式
- ✅ NPU 调用：视觉端点实际触发 ZhouyiExecutionProvider
- ✅ 后端解耦：LLM 后端（llama-server）可独立替换
- ✅ 延迟合理：分类 2.51ms、检测 13.36ms 与单独 NPU bench 一致

## 部署文件

- app/main.py：FastAPI 应用（5.5KB）
- 依赖：fastapi 0.162.4, uvicorn 0.54.0, httpx 0.28.1, pydantic 2.14.3
- 启动命令：
  source /opt/edge-ai-lab/venv/bin/activate
  LD_LIBRARY_PATH=/usr/share/cix/lib:/usr/share/cix/lib/onnxruntime:$LD_LIBRARY_PATH
  cd /opt/edge-ai-lab/services/api && python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000
